# Hanz Tyrone P. Dela Cruz — E-Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript. It is ready to open and edit in Visual Studio Code.

## Open in Visual Studio Code
1. Extract `HanzTyrone_EPortfolio.zip`.
2. Open Visual Studio Code.
3. Select **File → Open Folder...** and choose the `hanztyrone_eportfolio` folder.
4. Open `index.html` in a browser. For live preview, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation and current footer year
- `assets/profile.jpg` — portrait cropped from the supplied resume image
